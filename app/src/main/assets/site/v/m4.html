本月活动

每项活动标注的年龄是参考范围，不是必须达到的时间。

A01

面对面声音轮流

0—9月；语言／社交。

准备安静环境、成人面孔。

安全不用强光、响声或持续逗弄。

  1. 1在儿童清醒时面对面；

  2. 2成人说短句或模仿发声；

  3. 3停顿；

  4. 4回应儿童的声音、表情或目光。

观察
注视、发声、自发停顿和愉快参与。
调整或暂停
转头、哭闹、明显疲劳。

A03

清醒趴玩

婴儿期（清醒、看护下），按能力；大运动。

准备安全平坦活动垫、成人。

安全睡眠始终仰卧；不在高处或软床练习。

  1. 1仅在清醒时置于安全平面；

  2. 2成人近距离看护；

  3. 3用声音和面孔互动；

  4. 4逐步增加适应机会。

观察
头颈姿势、前臂支撑及舒适度。
调整或暂停
呼吸异常、持续哭闹、明显不适。

A04

看手与自主抓握

3—8月；精细动作／认知。

准备轻便无小零件玩具。

安全定期检查玩具零件是否松脱。

  1. 1放在儿童可看到的位置；

  2. 2等待伸手；

  3. 3玩具轻触掌侧或放至近处，允许主动尝试。

观察
目光、碰触、抓握探索。
调整或暂停
烦躁、反复回避。

A09

安全镜面表情互动

4—12月；社交／视觉。

准备牢固固定的婴儿安全镜。

安全镜面牢固不碎裂、无细小装饰。

  1. 1成人与儿童一起看镜面；

  2. 2表情回应；

  3. 3指出人脸；

  4. 4不要求识别自我。

观察
看脸、微笑、发声。
调整或暂停
明显困扰。
