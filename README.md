# 成长手册安卓版

把《0–3岁婴幼儿家庭早期发展与养育实施手册》装进安卓手机：全部 45 页内容随应用安装，不需要网络；勾选记录和出生日期保存在应用里，不会被浏览器清除；填写出生日期后，接种和儿保日期前 3 天和当天 9 点在手机上提醒。

## 下载安装包

每次向 `main` 分支提交，GitHub 都会自动生成新的安装包：打开仓库首页右侧的 **Releases**，在手机上下载最新的 `growth-handbook-1.N.apk`。生成进度可在 **Actions** 页查看。

## 安装与更新

- 在手机上打开下载的 APK，按提示允许“安装未知应用”，点安装。
- 第一次填写出生日期时，手机会询问是否允许通知，选“允许”才能收到接种和儿保提醒。
- 内容更新后，替换 `app/src/main/assets/site/index.html` 并提交，GitHub 会自动生成新版本；新版本直接覆盖安装，勾选记录和出生日期保留。
- 不要卸载后重装，卸载会清除应用里保存的记录。

## 说明

- 适用于安卓 7.0 及以上。
- 安装包的签名文件不在仓库中，由构建流程从仓库的 Secrets（`HB_KEYSTORE_B64`、`HB_KEYSTORE_PASSWORD`）写入。签名文件须另行妥善保管：一旦丢失，已安装的应用将无法覆盖更新。
- 两台手机的勾选记录各自保存，不会互相同步。
