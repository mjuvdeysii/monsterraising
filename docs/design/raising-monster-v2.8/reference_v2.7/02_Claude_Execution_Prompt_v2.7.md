## 任务边界与设计决策

- **保留**四大 Tab（今天/手帐/目录/记录）、底部 **IP 化标签栏**、双小怪兽现有出场方式、47 屏业务功能、绘本成长地图、深色外观、贴纸册。
- **不执行**将 IP 底部 Tab 改为纯线性图标、强制减少怪兽用量等与用户决定冲突的改动。这两项只在决策清单中记录为“已拒绝/待用户重新确认”，不反复提出或暗中修改。
- **不裁切**主体插画的头部与重要材料，优先修正容器比例、留白、响应式排版；除非逐资产确认安全裁切范围。
- **保留**历史用户记录的原始含义；不静默修改“完成”、“看过”、“做过”、“接种”的既有数据含义。任何迁移须有字段映射、测试和回滚方案。
- 平台行为分别验证：Android 系统 Back/预测性返回与 Insets；iOS Safe Area/交互返回/Tab 行为。复用成熟导航、动画和 WebView 桥接能力，不无谓改技术栈。
- 适用于家长碎片化操作：核心路径的浏览效率、数据可靠性和可访问性优先于展示型动效。

## Stage 1｜信息架构、排版与 IP 组件精修

**批次 1A（低风险基础）**：新增/整合语义 token，检查颜色对比、文字样式、4/8 间距、16/20 容器边距、12/16/20 圆角及最小触控热区；要求两套怪兽×深浅主题一致。保留双 IP tab 且分别定义 normal/selected/pressed/focus/disabled 的可读性；不要擅自替换图标。

**批次 1B（真实屏幕）**：按 A1、C1、C2、C6、D1 优化层级：
- A1：宝宝月龄 → 一张今日建议 → 有可恢复内容才展示继续 → 记一条/看本月 → 更多工具。每个入口真实可用。
- C1：在月龄切换区域明确“宝宝现在 X 月”、“正在看 Y 月”；±2 快速切换 + “全部月份” Sheet；不能重现无语义小圆点。测试 0 与 36 边界。
- C2：绘本成长地图保留，跳到当前节点可见，不引入强制卡通循环动效。
- C6：图片不裁头；标题与状态文字同源；内容单列易读，长字放大不截断。
- D1：最近记录优先；观察、活动、接种儿保各自统计；贴纸保留但进入纪念区。

**本批验收**：提供每屏“原版 2.6.52 截图 → 修改稿截图 → 同任务操作录屏”；先说明用户实际要完成的任务，再说明怎样减少寻找与误触。不得提交美化后但删除操作入口的静态稿。

## Stage 2｜状态语义与数据一致性（P0 优先）

1. 建立“内容看过 / 活动做过 / 真实观察 / 接种儿保已确认 / 手帐事件 / 贴纸”独立状态字典，确认 API 和数据库实际字段。
2. A4 过往批量补看只修改**明确选中的内容阅读/活动字段**；**接种儿保必不自动修改**。活动仅在家长主动确认后才写实际做过。历史迁移不重新推断儿童能力。
3. C7–C9 完成与撤销须操作实际记录、支持跨页面更正；日志/统计中每个分母、口径和事件时间真实可追溯。
4. 月龄状态分离 `currentMonth / browsedMonth`；快速切换后取消旧请求或校验响应序号；路线和 UI 标题同源。
5. 本地存储写入成功后才能显示“已存到本机”；若设计支持云端同步，要有待同步/失败/冲突语义；没有云服务不能造同步已完成。

## Stage 3｜计时、历史恢复与平台交互

- B2–B4 检查真实计时状态机，确保锁屏、前后台、被系统回收、重启、跨午夜、手动改时间、连续点击、从小组件/通知回到应用等情形不重复写入或无依据计算时长。
- 为每条计时事件建立稳定唯一 ID、持久化时间记录、状态恢复规则；时间线修改保留来源与历史数据。
- 完整审查来源返回：今日推荐 → 活动，搜索 → 月龄，地图 → 月龄，手帐 → 编辑，贴纸 → 详情；恢复 tab、滚动、筛选、浏览月龄和编辑草稿。现有返回逻辑若符合要求，**仅补测试，不重复重写**。
- WebView 与原生壳之间的 Back、系统字体缩放、Reduce Motion、safe-area、IME/键盘、照片与导出权限应明确由哪层负责，并分别在 Android/iOS 真机验证。
- 若后端/原生模块当前无法覆盖某项测试，写“未实现/未验证/环境阻塞”，不可用模拟结果代替真机通过。

## Stage 4｜Motion、插画保真及性能

- 不做全局统一 scale 缩图。记录每张首屏主插画原始宽高比、安全裁切区、角色焦点和容器布局，在 360/390/430 逻辑宽度及 iOS 大字体下对比。
- 动效按 `press 80–150ms`、`toggle 120–180ms`、`monthSwitch 180–240ms`、`navigation 220–300ms`、`monsterJoy 300–550ms` 起步；已有原生系统过渡不强制覆盖。
- 加载列表图片预留尺寸；按压下一可见帧即反馈；手势拖动期间不逐帧触发整个页面布局。减弱动画开启时动画依赖的功能仍可完成。
- 记录真机的设备/OS/刷新率/Release 或 Profile 构建/测试场景/丢帧与长帧情况；不能只报告“60fps”。

## Stage 5｜逐批真实验收、回归、提交

按 `03_Acceptance_Test_Cases.csv` 测试，填充实际结果（通过/失败/阻塞/未执行）、证据文件、设备和构建版本，**不覆盖原测试计划**，建议另存 `qa-results-v2.7.csv`。

发布阻断：数据错误/丢失/重复，接种状态被批量误改，安全/隐私信息缺漏，编辑草稿丢失，核心操作被遮挡或返回错误。

关注 iOS App Review 4.2“最低功能要求”：网页内核不天然不合格，但须确保应用提供真实实用功能、适宜 App 的操作/权限/性能与必要的原生集成；审核是否通过由 Apple 判定。配置 TestFlight 所需密钥前，逐条说明其用途，不在聊天或日志暴露凭据。
